MARVEL EXPERIENCE — versione app per telefono

Questa cartella contiene una PWA installabile: non richiede App Store/Play Store.

PUBBLICAZIONE
1. Carica TUTTA la cartella su un hosting statico con HTTPS (GitHub Pages, Netlify, Vercel, Cloudflare Pages, ecc.).
2. Apri il link dal telefono.
3. iPhone/iPad: Safari -> Condividi -> Aggiungi alla schermata Home.
4. Android: Chrome -> menu ⋮ -> Installa app / Aggiungi alla schermata Home.

IMPORTANTE
- I dati di Alessandro e Giuliana vengono salvati nel browser del dispositivo tramite localStorage.
- Il file Python originale e' incluso come backup e NON e' stato modificato.
- Il link video esclusivo resta quello presente nel file originale (https://drive.google.com/your-video-link-here): sostituiscilo con il tuo vero link quando vuoi.
- Perche' l'installazione PWA funzioni, usa HTTPS (oppure localhost per i test).
